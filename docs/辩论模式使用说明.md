# 辩论模式：多模型子代理互评

## 是什么

"辩论模式"是一个 DSH Agent preset：让主 agent（DeepSeek）把活儿派给 GPT（Codex）和 Claude（Claude Code）两个子代理，多轮互评、由主 agent 纠偏收口，用于复杂架构评审等需要多视角交叉验证的场景。

## 依赖（每台机器）

| 依赖 | 说明 |
|---|---|
| `dsh` | DeepSeek Harness CLI |
| `codex` CLI | 对应 GPT 子代理（`subagent_codex` 工具） |
| `claude` CLI | 对应 Claude 子代理（`subagent_claude_code` 工具） |
| `ffmpeg` | 抽帧/视频合成等（非辩论必需，但常见任务用到） |

## 关键配置

- `presets/debate/agent.cordis.yml`：挂载 `subagent` / `subagent_fork` / `subagent_codex` / `subagent_claude_code` / `workflow` / `ralph` 等工具。
- `host-patch/cordis.patch.yml`：注册 `subagent-codex` 与 `subagent-claude-code` 两个 provider；并把 Claude Code 路由到 DeepSeek 的 Anthropic 兼容端点（`https://api.deepseek.com/anthropic`），避免要求 Anthropic 登录。

## 分工建议

| 角色 | 模型 | 职责 |
|---|---|---|
| 主 agent | DeepSeek v4-pro | 拆题、统筹、纠偏、收口 |
| GPT（Codex） | 主力 | 出方案、写稿、出活 |
| Claude（Claude Code） | 评审 | 挑硬伤、审可靠性 |

## 已踩过的坑

1. **Codex 缺 `codex-code-mode-host`**：如果 `codex` 是 symlink（如指向 ChatGPT.app），它按自身路径找 host，可能报 `failed to spawn code-mode host`。修复：`ln -s <真实路径>/codex-code-mode-host ~/.local/bin/codex-code-mode-host`。
2. **Claude Code 报 `Not logged in`**：本机没登录 Anthropic 时，必须走 DeepSeek 端点。见 `host-patch/cordis.patch.yml` 里的 `env` 配置（用 `!!js` 从 `~/.dsh/.credentials.yaml` 读 Key，不硬编码）。
3. **子代理聊天记录不落盘**：DSH 的 Codex/Claude provider 是 one-shot、`persistSession: false`，只回传 final answer，中间步骤不持久化。要留痕要么改 DSH 源码（加 persistSession 配置），要么临时手动 `claude -p`（会落盘到 `~/.claude/projects/`）。

## 使用方式

1. 起 `dsh web`，选「辩论模式」preset。
2. 给主 agent 一个复杂任务（如"评审某架构方案"）。
3. 主 agent 会派 `subagent_codex` / `subagent_claude_code` 做多轮互评，最终收口。
